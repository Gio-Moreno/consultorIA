# Tu consultorIA de marketing

Página para instalar el Consultor de Marketing de Gio Moreno en ChatGPT, Claude o Gemini con un toque.

## Archivos

- `index.html`: la página. Trae las instrucciones del consultor dentro, listas para copiarse.
- `guia.txt`: la guía completa del proceso. El consultor la abre cuando la necesita (modos Exprés y Completo).

Los dos archivos deben estar en la misma carpeta.

## Publicar en GitHub Pages

1. Entra a github.com y crea un repositorio nuevo: **New repository**. Nombre sugerido: `consultoria-marketing`. Márcalo como **Public** y toca **Create repository**.
2. En el repositorio vacío, toca **uploading an existing file**, arrastra `index.html` y `guia.txt`, y toca **Commit changes**.
3. Ve a **Settings → Pages**. En **Source** elige **Deploy from a branch**, en **Branch** elige `main` y la carpeta `/ (root)`, y toca **Save**.
4. En uno o dos minutos la página queda en: `https://TU-USUARIO.github.io/consultoria-marketing/`

Ese es el enlace para el código QR de la presentación.

## Gemini con un solo toque (opcional)

Si creas un Gem en Gemini con las instrucciones y la guía como conocimiento, y lo compartes con "Cualquier persona con el enlace", el botón de Gemini puede abrirlo ya instalado, sin copiar ni pegar. Abre `index.html`, busca la línea `var GEM_URL = '';` y pega el enlace del Gem entre las comillas.
